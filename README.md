# 🔒 Advanced System Monitor Tool

A cross-platform Python utility for authorized system monitoring and automation tasks.

---

## 📌 Overview

This tool is designed for system administrators and security professionals to perform authorized monitoring and automation tasks in controlled environments.

### Key Capabilities:
- 📸 Remote screenshot capture
- 🎥 Webcam imaging (with user consent)
- 🎙️ Audio recording (for authorized testing)
- ⌨️ Input simulation and automation
- 📋 Clipboard management
- 💻 System information retrieval
- 📡 Discord-based reporting
